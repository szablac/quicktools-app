# Nyitó prompt – új projekt indítása

> Ezt a szöveget másold be **első üzenetként** egy friss Claude Code munkamenetben, miután ebből a sablonból létrehoztad az új projekt mappáját (és megnyitottad benne Claude Code-ot).

---

Ez egy új projekt, a `project-skeleton` sablonból indul. Olvasd el a `CLAUDE.md` fájlt és az `ACTIVE_TASK.md` fájlt, majd indítsd el a `CLAUDE.md` 0. szakasza szerinti projektindítást.

Az első kérdésed legyen: **Mi az, amit fel fogunk építeni?**

A válaszom (a projektterv) alapján lépj tervező módba: vidd végig velem a `docs/01_PROJECT_FOUNDATIONS.md` kérdéskeretét, közben folyamatosan töltsd ki a kapcsolódó dokumentumokat (`01_PROJECT_FOUNDATIONS.md`, `03_ARCHITECTURE.md`, `04_DOMAIN_RULES.md`, `roadmap/00_MASTER_PLAN.md`, `10_BACKLOG.md`). Tervezés közben kódot ne írj.

Amint egy backlog-tétel `READY` állapotba kerül, kérj kifejezett jóváhagyást, mielőtt fejlesztést kezdenél — és onnantól: kis lépések, egyszerű javaslatok, egyszerű de hatékony tesztek.
