PDF Page Selector

Upload a PDF, select pages by clicking, then download the result — the file never leaves your browser.

Upload a different file

Two modes are available, pick whichever is faster for what you want to select:
Keep mode — only the pages you select below end up in the new PDF, everything else is left out.
Remove mode — the opposite: the pages you select are dropped, everything else stays in the new PDF.
